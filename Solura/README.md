# Serene - Meditation App

A beautiful React Native meditation and mindfulness app built with Expo.

## Features

- **Home Screen**: Browse featured meditation sessions, collections, and recent sessions
- **Explore Screen**: Discover meditation categories and popular sessions
- **Stats Screen**: Track your meditation progress with weekly, monthly, and yearly views
- **Profile Screen**: Manage your account settings and preferences

## Tech Stack

- React Native with Expo SDK 54
- Expo Router for navigation
- TypeScript
- Lucide React Native for icons
- Google Fonts (Inter & Manrope)
- Linear Gradients for beautiful UI effects

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for web:

```bash
npm run build:web
```

## Navigation Structure

The app uses tab-based navigation with four main screens:

- **Home** - Main dashboard with today's session and collections
- **Explore** - Browse categories and discover new sessions
- **Stats** - View your meditation statistics and achievements
- **Profile** - Account settings and preferences
